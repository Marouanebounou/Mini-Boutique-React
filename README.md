# Mini Boutique

Small e-commerce shop built with React.

## Features

- Product list with a category filter
- Product cards and shopping cart
- Add-product page
- 404 page with React Router

## Tech stack

React · Vite · React Router · Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```
